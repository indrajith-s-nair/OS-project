# OS Memory Simulator

## Tech Stack
- Framework: Next.js 16 (App Router)
- Library: React 19
- Language: TypeScript
- Styling: Tailwind CSS 4, PostCSS
- UI and Animation: shadcn/ui (@base-ui/react), Lucide React, Framer Motion
- Package Manager: pnpm

## Getting Started

### Prerequisites
- Node.js (v20 or higher)
- pnpm (or npx pnpm)

### Installation
```bash
pnpm install
```

### Run Development Server
```bash
pnpm dev
```
Open http://localhost:3000 in your browser.

### Production Build
```bash
pnpm build
pnpm start
```
